One emoji, nothing else: 🥲 (U+1F972, Smiling Face with Tear) — a warm, sincere smile with a single tear of being moved. Running `main.py` prints that exact emoji to stdout and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
python3 main.py
```
